# demux.ro

The demux website — a small software studio focused on vision systems, embedded/IoT,
green energy software, and web app integrations. Dark, high-contrast design with a
bold hero, terse pillar cards, and industry deep-dive sections.

```bash
cd web
npm run dev
```

Four pages: Home, Services, About, Contact.

Deployed as a static export to GitHub Pages (see `.github/workflows/deploy.yml`), with
Cloudflare in front for DNS, TLS, and edge security headers.
