# demux.ro

Two homepage directions for demux, a small software studio focused on vision systems,
embedded/IoT, green energy software, and web app integrations. Each variant is a
standalone Next.js app — pick one, delete the other, and continue building on it.

## variant-a-retool

Dark, high-contrast, enterprise/technical tone — inspired by retool.com's visual language.
Bold single-statement hero, terse pillar cards, industry deep-dive sections.

```bash
cd variant-a-retool
npm run dev
```

## variant-b-mercury

Light, clean, friendly tone — inspired by mercury.com's visual language. Card-driven
feature grid, "how we work" process steps, dual CTAs.

```bash
cd variant-b-mercury
npm run dev
```

Both apps include four pages: Home, Services, About, Contact.
